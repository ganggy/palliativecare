Nurse Data Entry Manual

คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

ระบบ Palliative Home Visit พร้อมภาพหน้าจอตามขั้นตอน เพื่อให้บันทึกข้อมูลถูกต้อง ครบถ้วน ตรวจย้อนหลังได้ และพร้อมใช้ต่อในงานบริหาร ห้องบัตร และการเบิกจ่าย

จัดทำจากหน้าจอระบบจริง วันที่ 18 พฤษภาคม 2569

ภาพรวมการทำงานของพยาบาล

ลำดับการทำงานที่แนะนำคือ ค้นหา/ยืนยันคนไข้ → ตรวจทะเบียน → บันทึกเยี่ยมบ้าน → แนบรูป → ทำ ACP/LW ถ้ามี → ตรวจภาพรวมก่อนจบวัน

ก่อนบันทึก

  • เลือกคนไข้ถูกคนด้วย HN/CID
  • วันที่เยี่ยมเป็นวันที่ไปเยี่ยมจริง
  • มี Authen code ถ้ามีในวันนั้น
  • บันทึกอาการติดตามและหมายเหตุอ่านเข้าใจ

ข้อมูลคลินิก

  • T/P/RR/BP ถูกต้อง
  • PPS สอดคล้องกับสภาพจริง
  • ระบุ ESAS/CC และอาการรบกวน
  • ประเมิน pain score และการจัดการปวด

รูปภาพ

  • มีรูปบัตรคู่กับคนไข้เมื่อจำเป็น
  • มีรูปติดตามอาการหรือแผล
  • เพิ่มรูปที่ 2/3 ได้หากต้องใช้
  • เปิดรูปดูได้หลังบันทึก

หลังบันทึก

  • มีข้อความบันทึกสำเร็จ
  • visit ปรากฏในประวัติ
  • Checklist ครบตามที่ทำจริง
  • ACP/LW มี PDF หากทำเอกสาร

มาตรฐานข้อความบันทึกที่แนะนำ

อาการวันนี้: ... ประเมิน: T ... P ... RR ... BP ... PPS ... Pain ... การดูแลที่ทำ: ... คำแนะนำแก่ญาติ/ผู้ดูแล: ... แผนติดตาม: ...
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

1. เข้าหน้างานพยาบาลหน่วย

  • ตรวจชื่อผู้ใช้งานและหน่วยบริการมุมขวาบนให้ตรงกับหน่วยของตนเอง
  • ดูตัวเลขภาพรวมก่อนเริ่มงาน เช่น คนไข้คงเหลือ ถึงกำหนดวันนี้ เยี่ยมเดือนนี้ และปีงบประมาณ
  • ใช้แถบเมนู ค้นหา/ยืนยัน, ทะเบียน, เยี่ยมบ้าน, ACP/LW และภาพรวม ตามลำดับการทำงาน
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

2. ค้นหาและยืนยันคนไข้

  • ค้นหาด้วย HN, CID, ชื่อ หรือรหัสโรค
  • ตรวจชื่อ-สกุล, HN, CID และหน่วยตามที่อยู่ก่อนกดยืนยัน
  • หากชื่อคล้ายกันให้ใช้ HN/CID เป็นหลัก ห้ามบันทึกหากยังไม่มั่นใจว่าเป็นคนไข้รายเดียวกัน
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

3. ตรวจทะเบียนและเลือกเคส

  • ใช้แท็บทะเบียนเพื่อตรวจสถานะ นัดถัดไป รอบ/เดือนการเยี่ยม และประวัติ visit
  • เลือกคนไข้ที่กำลังติดตามสำหรับงานประจำ และเลือกครบเงื่อนไขเมื่อต้องตรวจเคสที่ทำครบแล้ว
  • ใช้ช่องค้นหาเมื่อต้องการหาเคสด้วย HN/CID/ชื่อ/Dx อย่างรวดเร็ว
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

4. บันทึกข้อมูลผู้ป่วยและเริ่ม visit

  • ตรวจรายละเอียดผู้ป่วย เบอร์โทร ญาติ LINE ID และวันนัดถัดไป
  • ในฝั่งบันทึกเยี่ยมบ้านให้กรอกวันที่เยี่ยมจริง Authen code อาการติดตาม และหมายเหตุ
  • ถ้าบันทึกย้อนหลัง ให้ใช้วันที่ไปเยี่ยมจริง ไม่ใช่วันที่กรอกข้อมูล
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

5. กรอกประเมินทางคลินิก

  • กรอก T, P, RR, BP, PPS, pain score, ESAS/CC และอาการรบกวนตามข้อมูลจริง
  • เลือกการใช้ออกซิเจน การจัดการความปวด และผลข้างเคียงจาก Morphine ถ้ามี
  • หาก PPS หรืออาการเปลี่ยนแปลงมากจากครั้งก่อน ให้ระบุรายละเอียดในหมายเหตุ
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

6. แนบรูปภาพประกอบ visit

  • แนบรูปบัตรคู่กับคนไข้สำหรับยืนยันตัวตนและงานห้องบัตร
  • แนบรูปติดตามอาการ เช่น สภาพผู้ป่วย แผล อุปกรณ์ หรือสภาพแวดล้อมที่เกี่ยวข้อง
  • สามารถเพิ่มรูปมากกว่า 1 รูปได้ ตรวจว่ารูปเปิดดูได้หลังบันทึก
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

7. บันทึก ACP/Living Will และสร้าง PDF

  • เลือก visit ที่ต้องการผูกเอกสาร ACP/LW
  • ตรวจข้อมูลส่วนบุคคล วันเกิด สิทธิการรักษา สถานพยาบาลประจำ และผู้ร่วมวางแผน
  • ให้ผู้ป่วย/ผู้แทน/พยาน/บุคลากรเซ็นในระบบ แล้วกดสร้าง PDF และตรวจว่าดาวน์โหลดได้
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

8. ตรวจภาพรวมก่อนจบวัน

  • ตรวจจำนวน visit วันนี้ เดือนนี้ และปีงบประมาณของหน่วย
  • ดูทะเบียนหน่วยตัวเองและสถานะความพร้อมเบิก
  • ก่อนออกจากระบบให้ตรวจว่าทุก visit วันนี้บันทึกครบ รูปครบ และข้อมูลสำคัญไม่ตกหล่น
คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

ข้อผิดพลาดที่พบบ่อยและวิธีป้องกัน

ปัญหาวิธีป้องกัน
เลือกคนไข้ผิดคนตรวจ HN และ CID ก่อนกด ยืนยัน
วันที่เยี่ยมผิดใช้วันที่ไปเยี่ยมจริง ไม่ใช้วันที่กรอกย้อนหลัง
ไม่มีรูปแนบตรวจรูปก่อนกดบันทึก และดูจำนวนรูปหลังบันทึก
บันทึกอาการสั้นเกินไปเขียนอาการสำคัญ ผลการประเมิน และคำแนะนำที่ให้ญาติ
PPS ไม่สอดคล้องกับอาการเลือกคะแนนตามสภาพจริง และใส่หมายเหตุหากเปลี่ยนมาก
ACP/LW ไม่มีลายเซ็นให้เซ็นในระบบก่อนสร้าง PDF และตรวจว่าดาวน์โหลดไฟล์ได้

Checklist ก่อนออกจากระบบ

  • ทุก visit วันนี้ถูกบันทึกครบ
  • รูปภาพแนบครบและเปิดดูได้
  • Authen code ที่มีถูกกรอกแล้ว
  • ACP/LW ที่ทำวันนี้มี PDF และดาวน์โหลดได้
  • แจ้ง Case Manager หากพบคนไข้ผิดหน่วย เสียชีวิต ย้ายพื้นที่ หรือไม่เข้าเกณฑ์
