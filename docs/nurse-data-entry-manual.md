# คู่มือการบันทึกข้อมูลสำหรับพยาบาลหน่วย

คู่มือนี้ใช้สำหรับพยาบาล รพ.สต./PCU ที่บันทึกข้อมูลในระบบ Palliative Home Visit เพื่อให้ข้อมูลถูกต้อง ครบถ้วน ตรวจย้อนหลังได้ และพร้อมใช้ต่อในงานบริหาร/ห้องบัตร/การเบิกจ่าย

## 1. หลักสำคัญก่อนเริ่มบันทึก

- เข้าระบบด้วยบัญชีของตนเองเท่านั้น ห้ามใช้บัญชีร่วมกัน เพราะชื่อผู้บันทึกจะถูกเก็บกับ visit
- เลือกบทบาท `พยาบาลหน่วย` หรือบัญชีที่หน่วยอนุมัติแล้ว
- ตรวจสอบชื่อผู้ใช้งานมุมขวาบนให้ตรงกับหน่วยของตนเองก่อนเริ่มงาน
- ข้อมูลคนไข้ที่แสดงในหน้าพยาบาลต้องเป็นคนไข้ของหน่วยตนเอง หากพบคนไข้ผิดหน่วย ให้แจ้ง Case Manager/Admin ตรวจสอบก่อนบันทึก
- ทุก visit ควรมีวันที่เยี่ยม, อาการติดตาม, ข้อมูลประเมินสำคัญ และรูปภาพแนบอย่างน้อยตามเกณฑ์ของหน่วย

## 2. ขั้นตอนค้นหาและยืนยันคนไข้

1. เข้าเมนู `งานพยาบาลหน่วย`
2. เลือกแท็บ `ค้นหา/ยืนยัน`
3. ค้นหาด้วย HN, CID, ชื่อคนไข้ หรือรหัสโรค
4. ตรวจสอบข้อมูลก่อนยืนยัน ได้แก่ ชื่อ-สกุล, HN, CID และหน่วยตามที่อยู่
5. กด `ยืนยัน` เมื่อตรวจแล้วว่าเป็นคนไข้ที่ต้องการบันทึก

ข้อควรระวัง:

- หากชื่อคล้ายกัน ให้ใช้ HN หรือ CID เป็นหลัก
- หากไม่พบคนไข้ในหน่วย ให้ตรวจสอบว่า Case Manager ลงทะเบียน/มอบหมายหน่วยแล้วหรือไม่
- ห้ามบันทึก visit ให้คนไข้ที่ไม่แน่ใจว่าเป็นคนเดียวกัน

## 3. การดูทะเบียนคนไข้ของหน่วย

แท็บ `ทะเบียน` ใช้สำหรับดูคนไข้ในหน่วยและเลือกเคสเพื่อบันทึกหรือตรวจสอบประวัติ

ข้อมูลที่ควรตรวจ:

- สถานะคนไข้ เช่น กำลังติดตาม, ครบเงื่อนไข, ยกเลิก, เสียชีวิต
- นัดถัดไป
- เดือน/รอบการเยี่ยม
- ตารางเยี่ยมครั้งที่ 1-6
- ประวัติ visit จาก HOSXP และข้อมูลที่บันทึกในระบบ

การใช้งานที่ถูกต้อง:

- เลือก `คนไข้ที่กำลังติดตาม` เมื่อต้องบันทึกงานประจำ
- เลือก `ครบเงื่อนไขการติดตาม` เพื่อตรวจเคสที่ติดตามครบแล้ว
- ใช้ช่องค้นหาเมื่อต้องการหาเคสเร็วด้วย HN/CID/ชื่อ/Dx

## 4. การบันทึกข้อมูลผู้ป่วย

เมื่อเลือกคนไข้แล้ว ให้ตรวจสอบกล่อง `รายละเอียดผู้ป่วย`

ข้อมูลที่ควรกรอก/ปรับปรุง:

- เบอร์โทรผู้ป่วย
- เบอร์โทรญาติ
- LINE ID ถ้ามี
- วันนัดเยี่ยมถัดไป
- หมายเหตุสำคัญ เช่น ผู้ดูแลหลัก, ข้อจำกัดการเดินทาง, ข้อควรระวัง, อุปกรณ์ที่ต้องเตรียม

แนวทางบันทึก:

- เบอร์โทรให้กรอกเป็นเลขที่ติดต่อได้จริง
- หมายเหตุควรสั้น ชัดเจน และเป็นข้อมูลที่ทีมดูแลต่อใช้ประโยชน์ได้
- หากคนไข้เสียชีวิต ย้ายพื้นที่ หรือไม่เข้าเกณฑ์ ให้แจ้งผู้มีสิทธิ์ยกเลิก/เปลี่ยนสถานะ ไม่ควรลบหรือบันทึกทับแบบไม่อธิบาย

## 5. การบันทึกเยี่ยมบ้าน

เข้าแท็บ `เยี่ยมบ้าน` หลังเลือกคนไข้แล้ว กรอกข้อมูล visit ให้ครบตามจริง

ข้อมูลพื้นฐานที่ต้องบันทึก:

- วันที่เยี่ยม
- Authen code ถ้ามี
- อาการติดตาม
- หมายเหตุเพิ่มเติม
- Checklist การเยี่ยม
- ข้อมูลประเมินทางคลินิก
- รูปภาพประกอบ

### 5.1 วันที่เยี่ยม

- ใช้วันที่ไปเยี่ยมจริง
- หากบันทึกย้อนหลัง ให้ใส่วันที่เยี่ยมจริง ไม่ใช่วันที่กรอกข้อมูล
- ตรวจสอบเดือน/ปีให้ถูกต้อง เพราะมีผลต่อรายงานรายวัน รายเดือน และปีงบประมาณ

### 5.2 Authen code

- กรอกเมื่อมีรหัสจากระบบที่เกี่ยวข้อง
- ตรวจสอบตัวเลข/ตัวอักษรให้ครบ
- หากยังไม่มี ให้เว้นไว้ก่อนและกลับมาแก้ไขภายหลังได้

### 5.3 อาการติดตามและหมายเหตุ

อาการติดตามควรตอบคำถามว่า “วันนี้คนไข้เป็นอย่างไร และทีมทำอะไรไปบ้าง”

ตัวอย่างที่ดี:

- เหนื่อยน้อยลง รับประทานอาหารได้เล็กน้อย ญาติให้ยาตามแผน
- มีแผลกดทับก้นกบ ขนาดประมาณ 2 ซม. สอนญาติพลิกตะแคงและทำแผล
- ปวดท้องระดับ 6/10 ให้คำแนะนำการใช้ยาและนัดติดตามอาการ

ตัวอย่างที่ควรหลีกเลี่ยง:

- ปกติ
- ดีขึ้น
- เยี่ยมแล้ว

## 6. การประเมินทางคลินิกในการเยี่ยม

กรอกตามข้อมูลที่ตรวจ/ซักประวัติได้จริง

รายการสำคัญ:

- อุณหภูมิร่างกาย องศาเซลเซียส
- ชีพจร ครั้ง/นาที
- อัตราการหายใจ ครั้ง/นาที
- ความดันโลหิต เช่น `120/80`
- PPS score 0-100
- อาการสำคัญ/ESAS
- อาการรบกวน
- การใช้ออกซิเจน
- ตำแหน่งปวด
- ระดับปวด 0-10
- การจัดการความปวด
- ผลข้างเคียงจาก Morphine ถ้ามี

แนวทางกรอก PPS:

- เลือกคะแนนตามสภาพจริงของผู้ป่วยในวันที่เยี่ยม
- หาก PPS 10-50 ควรบันทึกอาการและแผนดูแลให้ชัดเจน
- หากมีการเปลี่ยนแปลงจากครั้งก่อนมาก ให้ระบุในหมายเหตุ

แนวทางกรอก ESAS/อาการสำคัญ:

- ระบุอาการที่คนไข้หรือญาติให้ความสำคัญที่สุด
- เขียนระดับความรุนแรงหรือผลกระทบต่อชีวิตประจำวันเมื่อทำได้
- หากไม่มีอาการเด่น ให้ระบุว่าไม่มีอาการเด่นและบันทึกสิ่งที่ประเมินแล้ว

## 7. การบันทึกรูปภาพ

ระบบแบ่งรูปเป็น 2 กลุ่ม

- `รูปบัตรคู่กับคนไข้`
- `รูปติดตามอาการคนไข้`

แนวทางถ่าย/แนบรูป:

- รูปบัตรคู่กับคนไข้ ใช้สำหรับยืนยันตัวตนและงานห้องบัตร
- รูปติดตามอาการ ใช้บันทึกสภาพคนไข้ แผล อุปกรณ์ หรือสภาพแวดล้อมที่เกี่ยวข้องกับการดูแล
- สามารถเพิ่มรูปมากกว่า 1 รูปได้ โดยกดปุ่มเพิ่มรูปในแต่ละกลุ่ม
- บนมือถือ iOS ให้เลือกได้ทั้งถ่ายรูปใหม่หรือเลือกรูปจากเครื่อง ถ้าเลือกไม่ได้ให้ลองเปิดผ่าน Safari/Chrome เวอร์ชันล่าสุด

ข้อควรระวังเรื่องรูป:

- หลีกเลี่ยงการถ่ายส่วนที่ไม่เกี่ยวข้องหรือกระทบความเป็นส่วนตัวเกินจำเป็น
- หากถ่ายแผลหรืออวัยวะเฉพาะส่วน ควรให้เห็นเฉพาะบริเวณที่จำเป็นต่อการติดตาม
- ตรวจสอบว่ารูปอัปโหลดสำเร็จก่อนออกจากหน้า
- หากรูปผิดคน ให้แจ้งผู้ดูแลระบบแก้ไขทันที

## 8. Checklist การเยี่ยม

Checklist ใช้ยืนยันว่างานสำคัญใน visit นั้นดำเนินการแล้ว

รายการที่ควรตรวจ:

- ประเมินอาการและอาการรบกวน
- ทวนรายการยา
- ประเมิน ADL หรือความสามารถช่วยเหลือตัวเอง
- ทบทวน ACP หรือเป้าหมายการดูแล
- ตรวจอุปกรณ์และเวชภัณฑ์
- อธิบายญาติ/ผู้ดูแล
- ถ่ายภาพผู้ป่วยแล้ว

หลักการเลือก:

- เลือกเฉพาะข้อที่ทำจริง
- หากยังไม่ได้ทำ ให้ไม่ต้องติ๊ก และระบุเหตุผลในหมายเหตุถ้าจำเป็น
- ระบบจะใช้ข้อมูลนี้ช่วยสรุปความพร้อมของ visit

## 9. การบันทึก ACP/Living Will

ใช้แท็บ `ACP/LW` เมื่อต้องการบันทึกแบบฟอร์ม ACP หรือ Living Will แนบกับ visit

ขั้นตอน:

1. เลือกคนไข้ก่อน
2. ไปที่แท็บ `ACP/LW`
3. เลือก visit ที่ต้องการผูกเอกสาร
4. ตรวจสอบข้อมูลส่วนบุคคล เช่น ชื่อ, อายุ, CID, วันเกิด, สิทธิการรักษา, สถานพยาบาลประจำ
5. กรอกผู้ร่วมวางแผน/ผู้ตัดสินใจแทน ถ้ามี
6. เลือกความต้องการและขอบเขตการรักษา
7. ให้ผู้ป่วย/ผู้แทน/พยาน/บุคลากรเซ็นในระบบตามความเหมาะสม
8. กด `สร้างและบันทึก PDF ACP/LW`
9. ตรวจสอบไฟล์ PDF และดาวน์โหลดได้จากลิงก์ที่ระบบแสดง

ข้อมูลขั้นต่ำที่ควรมี:

- ชื่อผู้แสดงเจตนา
- เลขบัตรประชาชน
- วันที่ทำเอกสาร
- ความต้องการหรือขอบเขตการรักษา
- ลายเซ็นผู้ป่วยหรือผู้ตัดสินใจแทน
- ลายเซ็นพยานอย่างน้อย 1 คน

## 10. การแก้ไขข้อมูลที่ส่งในวันนั้น

หากต้องแก้ไขข้อมูล visit ที่บันทึกในวันนั้น ให้เข้าเมนูรายงาน/ข้อมูลส่งรายวัน หรือเลือก visit เดิมจากหน้าพยาบาลตามสิทธิ์ที่ได้รับ

แก้ไขได้เมื่อ:

- วันที่เยี่ยมผิด
- Authen code ตกหล่น
- อาการ/หมายเหตุยังไม่ครบ
- ข้อมูลประเมินคลินิกผิดหรือขาด
- ต้องแนบรูปเพิ่มเติม

ข้อควรระวัง:

- ไม่ควรแก้ไขข้อมูลย้อนหลังโดยไม่มีเหตุผล
- หากแก้ไขจากข้อมูลเดิมมาก ควรใส่หมายเหตุอธิบาย
- ไม่ควรลบข้อมูลสำคัญที่ใช้ประกอบการดูแลหรือการตรวจสอบ

## 11. ตรวจสอบหลังบันทึกทุกครั้ง

หลังบันทึก visit ให้ตรวจดังนี้:

- มีข้อความแจ้งว่าบันทึกสำเร็จ
- visit ปรากฏในประวัติของคนไข้
- วันที่เยี่ยมถูกต้อง
- รูปภาพเปิดดูได้
- Checklist และข้อมูลประเมินคลินิกแสดงครบ
- หากทำ ACP/LW แล้ว PDF ดาวน์โหลดได้

หากไม่เห็นข้อมูลหลังบันทึก:

- กดรีเฟรช
- ตรวจสอบอินเทอร์เน็ต
- เข้าหน้าทะเบียนแล้วเลือกคนไข้ใหม่
- หากยังไม่พบ ให้แจ้ง Admin/Case Manager พร้อม HN, วันที่เยี่ยม และเวลาที่บันทึก

## 12. ข้อผิดพลาดที่พบบ่อยและวิธีป้องกัน

| ปัญหา | วิธีป้องกัน |
| --- | --- |
| เลือกคนไข้ผิดคน | ตรวจ HN และ CID ก่อนกด `ยืนยัน` |
| วันที่เยี่ยมผิด | ใช้วันที่ไปเยี่ยมจริง ไม่ใช้วันที่กรอกย้อนหลัง |
| ไม่มีรูปแนบ | ตรวจรูปก่อนกดบันทึก และดูจำนวนรูปหลังบันทึก |
| บันทึกอาการสั้นเกินไป | เขียนอาการสำคัญ ผลการประเมิน และคำแนะนำที่ให้ญาติ |
| PPS ไม่สอดคล้องกับอาการ | เลือกคะแนนตามสภาพจริง และใส่หมายเหตุหากเปลี่ยนมาก |
| ลืม Authen code | เว้นไว้ก่อนได้ แต่ต้องกลับมาแก้เมื่อได้รหัส |
| ACP/LW ไม่มีลายเซ็น | ให้เซ็นในระบบก่อนสร้าง PDF |

## 13. Checklist ก่อนจบงานประจำวัน

- ตรวจว่าทุก visit วันนี้ถูกบันทึกครบ
- ตรวจว่ารูปภาพแนบครบและเปิดดูได้
- ตรวจว่า Authen code ที่มีถูกกรอกแล้ว
- ตรวจเคสที่มีอาการเปลี่ยนแปลงมากและบันทึกหมายเหตุชัดเจน
- ตรวจ ACP/LW ที่ทำวันนี้ว่ามี PDF และดาวน์โหลดได้
- แจ้ง Case Manager หากพบคนไข้ผิดหน่วย, เสียชีวิต, ย้ายพื้นที่, หรือไม่เข้าเกณฑ์

## 14. มาตรฐานข้อความบันทึกที่แนะนำ

รูปแบบสั้นที่ใช้ได้:

```text
อาการวันนี้: ...
ประเมิน: T ... P ... RR ... BP ... PPS ... Pain ...
การดูแลที่ทำ: ...
คำแนะนำแก่ญาติ/ผู้ดูแล: ...
แผนติดตาม: ...
```

ตัวอย่าง:

```text
อาการวันนี้: เหนื่อยเวลาเดิน รับประทานอาหารได้น้อย ไม่มีไข้
```
